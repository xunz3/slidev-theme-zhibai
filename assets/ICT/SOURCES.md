# ICT identity assets

`signature-official.png` is the unmodified horizontal signature from the Institute of Computing Technology, Chinese Academy of Sciences website:

- Source page: https://www.ict.ac.cn/
- Original asset: https://www.ict.ac.cn/images/header_ict.png
- Retrieved: 2026-09-16; 569 × 86 pixels, 21,054 bytes.
- The website stylesheet, https://www.ict.ac.cn/images/common_ict.css, uses `#0055a2`. The theme uses this blue as a design reference, not as a claim about an official identity specification.

Institutional names and marks remain the property of their respective owners; the theme's MIT license does not relicense those marks. The bundled signature is rendered with its original proportions. Dark mode uses a monochrome CSS treatment.

The pre-existing `emblem.svg` and `emblem-name-bilingual-stacked.svg` remain in the source repository but are not included in the npm package.
