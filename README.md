# slidev-theme-lilas

[![NPM version](https://img.shields.io/npm/v/slidev-theme-lilas?color=3AB9D4&label=)](https://www.npmjs.com/package/slidev-theme-lilas)

A Slidev theme with three presets — `default`, `ucas`, and `ict` — and light/dark support. Works with ordinary Slidev Markdown and content generated by `obsidian-slidev`.

## Preset design

| Preset | Visual direction | Motion |
| --- | --- | --- |
| `default` | Ivory and lilac, large editorial serif titles, an original folded-line illustration | Soft 620 ms rise, staggered line drawing |
| `ucas` | Ivory and pale blue, the original blue university signature and seal, orbital lines and restrained gold details | Measured 700 ms rise, rings drawn into view |
| `ict` | Cool white throughout, clear sans-serif titles, fine blue-green geometry and small sage details | Brief 480 ms horizontal entry, traced geometry |

Light mode uses pale surfaces throughout, including covers, section dividers, statements, and closing slides. Deep blue and navy backgrounds are reserved for dark mode. Content slides use fine footer rules, tabular page numbers, and simple margin notes. Section dividers carry each preset's visual motif: folded lilac lines, orbital studies, or a computational lattice. Original institutional artwork retains its own colors when a slide overrides the content accent.

Motion runs once on the active presentation slide: the composition enters, the illustration draws, and subtitles and author details fade in. It replays when revisiting a slide and leaves Slidev's `v-click` sequencing and authored transitions intact. Reduced-motion preferences, overview/next-slide previews, and print/export rendering stay static. No new frontmatter is required.

The original decorative SVGs are generated locally, so they remain sharp at any resolution and require no downloads. Covers with an `image` reserve a separate visual column and hide the decorative illustration. Longer English and Chinese frontmatter titles use a smaller display size automatically.

```bash

```

## Quick start

In your Slidev project:

```bash
pnpm add slidev-theme-lilas
```

Add to `slides.md`:

```md
---
theme: slidev-theme-lilas
layout: cover
title: My Presentation
subtitle: An optional subtitle
authors:
  - name: Your Name
    institution: Your Institution
themeConfig:
  presentation:
    preset: default
---

---
layout: default
---

# Introduction

Your content here.
```

## Configuration

Set deck-wide options under `themeConfig.presentation`:

| Option | Values | Default |
| --- | --- | --- |
| `preset` | `default`, `ucas`, `ict` | `default` |
| `accent` | CSS color | Preset color |
| `artwork` | `auto`, `none`, `folds`, `orbits`, `lattice`, `flow`, `field`, `dots`, or a custom image object | `auto` |
| `density` | `compact`, `normal`, `relaxed` | `normal` |
| `chrome` | `auto`, `on`, `off` — footer visibility | `auto` |
| `header` | Show slide title/subtitle in the header | `false` |
| `footerAuthors` | Show author names in the footer | `true` |
| `pageNumber` | Show page numbers | `true` |

Keep `title`, `subtitle`, `authors`, and `footer` at the frontmatter root. Authors can be names or objects with `name`, `institution`, and `email`. The center footer uses `footer`, falling back to the deck title.

Override an individual slide with `presentationPreset`, `presentationArtwork`, `presentationDensity`, `presentationChrome`, `presentationHeader`, `accent`, `footerAuthors`, or `pageNumber`:

```yaml
layout: default
presentationPreset: ucas
presentationDensity: compact
accent: "#345f8f"
footer: Results
```

### Choose the artwork independently

The preset controls typography, colors, and institutional identity. The artwork selects the decorative right-hand composition on covers, sections, and closing slides. Every built-in motif works with every preset and follows its light/dark palette.

```yaml
themeConfig:
  presentation:
    preset: ict
    artwork: flow
```

| Artwork | Composition |
| --- | --- |
| `auto` | Original preset motif: Default → `folds`, UCAS → `orbits`, ICT → `lattice` |
| `folds` | A continuous study of folded lines |
| `orbits` | Concentric rings; UCAS also displays its seal on covers and closing slides |
| `lattice` | Nested geometric volumes |
| `flow` | Fine flowing lines and a few connecting points |
| `field` | A soft color field and a circular contour |
| `dots` | An open, deterministic field of points |
| `none` / `false` | Remove the decoration and release its reserved text width |

Choose a different motif on an individual slide:

```yaml
layout: cover
presentationPreset: ucas
presentationArtwork: dots
```

`presentationArtwork: auto` returns that slide to its preset's original motif, even when the deck selects another artwork. Omitted or invalid values inherit the deck setting. An explicit object replaces the whole deck artwork configuration. The institution's main signature stays visible when artwork is changed or disabled; the extra UCAS seal appears only with `orbits`.

### Use your own SVG or image

Put an SVG, PNG, WebP, or other browser-supported image in your Slidev project's `public/artwork/` directory, then reference it with `/artwork/...`. A full HTTPS image URL also works. SVG files remain external images; their contents are not injected into the page.

```yaml
layout: cover
presentationArtwork:
  type: custom
  src: /artwork/my-research.svg
  darkSrc: /artwork/my-research-dark.svg
  fit: contain
  position: center
  opacity: 0.8
```

The same object can be used as `themeConfig.presentation.artwork` for the whole deck. `type: custom` can be omitted when `src` is supplied. `darkSrc` is optional; a single image is reused in both modes. `fit` accepts `contain` (the whole image) or `cover` (fill and crop); `position` accepts CSS position keywords or percentages such as `right center` or `70% 50%`. Opacity is clamped to 0–1 and can also be set on a built-in motif, for example `{ type: flow, opacity: 0.6 }`.

Artwork is decorative and hidden from assistive technology. Use the existing `image` / `imageAlt` cover options for a figure that communicates content. An authored cover `image` or full-slide `background` takes precedence over decorative artwork. Failed custom images are hidden; an available light/dark counterpart is used as the fallback. The theme's entrance animations are disabled in print/export and reduced-motion mode.

Compare the options in the [artwork gallery](./fixtures/artwork-gallery.md), including custom light/dark SVGs and covers without decoration:

```bash
pnpm exec slidev fixtures/artwork-gallery.md
```

These options are ordinary Slidev frontmatter and can be written in an Obsidian deck. Local artwork must be available in the generated Slidev workspace's `public` directory, or use an HTTPS URL.

## Layouts and components

| Layout | Use |
| --- | --- |
| `cover`, `intro` | Opening and introduction |
| `section`, `toc` | Section dividers and a TOC built from them |
| `default`, `center`, `two-cols` | Content; use `::right::` for the second column |
| `statement`, `quote` | Takeaways and quotations; quotes accept `author` and `source` |
| `figure`, `image-left`, `image-right` | Figures and image/text slides |
| `code`, `references` | Code and bibliography |
| `end` | Closing; optionally add `contact`, `showAuthors`, `logo`, and `logoAlt` |

Components are available directly in Markdown:

```md
<Callout type="tip" title="Key idea">

Explain the idea here.

</Callout>

<Figure src="/result.png" alt="Description of the result" caption="Figure 1. Results" />
```

Also available: `Authors`, `Steps`, `Timeline`, `Tag`, `Badge`, and `Kbd`. Put an ordered list inside `Steps` or `Timeline`.

```md
<Badge tone="positive" marker>Reproduced</Badge>
<Tag>experiment / 03</Tag>
<Kbd :keys="['Ctrl', 'Enter']" />
```

Content pages use quiet table rules, unboxed author details, and a consistent title rhythm. Code uses a larger reading size and a lightly tinted surface: short examples fit their content, while long examples scroll inside the code area. `density: compact` keeps dense material practical; `relaxed` adds space and increases text size. Figure captions retain readable text rather than technical label styling.

The `toc` layout accepts `showNumbers: false` for an unnumbered outline. Numbered entries use two-digit labels, and linked entries support pointer and keyboard navigation. In `two-cols`, `gap` sets the space between two equally sized columns; `reverse: true` swaps their visual order on wide screens. Narrow screens retain source order.

For image/text layouts, set `image`, `imageAlt`, and optionally `caption`, `backgroundSize: contain` or `cover`, and `mediaRatio` (30–70). The `figure` layout supports `figureVariant: centered`, `stage`, `minimal`, or `editorial`; use `variant` on a standalone `Figure`.

See [example.md](./example.md) and the preset decks: [default](./fixtures/default-preset.md), [UCAS](./fixtures/ucas-preset.md), [ICT](./fixtures/ict-preset.md).

For a comparison of the same content across all three presets, preview [elements-gallery.md](./fixtures/elements-gallery.md) with `pnpm exec slidev fixtures/elements-gallery.md`. It includes outlines, callouts, tables, code, quotations, figures, references, authors, timelines, and closing slides.

## Obsidian

The theme styles callouts, media, links, and warnings generated by [obsidian-slidev](https://github.com/xunz3/obsidian-slidev). Markdown conversion is handled by the plugin.

## Development

Requires Node.js 20.19+ and pnpm.

```bash
pnpm install --frozen-lockfile
pnpm run dev        # Preview example.md
pnpm run build      # Build the example
pnpm run export     # Export PDF
pnpm run quality    # Run checks
```

Use `build:default`, `build:ucas`, or `build:ict` for preset builds, and `screenshot:default`, `screenshot:ucas`, or `screenshot:ict` for PNG exports. `dev:fixture` previews the Obsidian integration fixture. Check reports are written to `.artifacts/quality/`.
