# Veil 0.4 implementation decisions

The user selected `veil-design-proposal.md` as the new visual target. It supersedes the 0.3 pure-white canvas and serif-body decisions. Preserve the existing preset/token/API/accessibility architecture. Implement directly in the existing theme; review the initial covers/content as the prototype before final acceptance.

- Paper / Folio / Blueprint use the proposal's exact light paper, accent and highlight colors. Ink dark canvases replace blue-gray. Neutral chrome/edges; accent and highlight have intentional semantic roles. Expose four chart colors through CSS variables.
- Display: Libertinus Serif 600 + Noto Serif SC 600. Reading: Inter 400 + Noto Sans SC 400, 18px / 1.55; Chinese 1.6 when explicitly language-tagged, punctuation hanging and progressive text-autospace. Labels 500; load that weight for Inter/Noto, use supported 600 for Libertinus. Shared scale: 12/14/16/18/21/28/36/48/64/96px.
- 64px short covers; long titles adapt within the existing canvas. 48px chapters with a pale 144px folio behind/above them. Statements reach 96px for short content, with length-aware reduction for long bilingual content. Do not clip content to meet an arbitrary display size.
- Covers rise from the lower part of the canvas into a bottom tonal meta band. Authored visuals occupy 5/12 opposite 7/12 text; the band spans both columns. Preserve explicit left/center cover alignment and native Markdown/visual slots.
- Use about 4rem horizontal content insets, practical vertical insets on the fixed 980×552 canvas. No decorative header/footer or column rules. Two-column gutter 4rem. Footer defaults to deck label + page; retain explicit legacy author opt-in to preserve API compatibility. Do not render an empty third column.
- Neutral, sentence-case authored eyebrows; do not forcibly rewrite user-authored strings in runtime. Remove CSS uppercase/wide tracking and update demo copy. Default gets the proposal's short fine eyebrow rule; ICT loses the old vertical/title and thick eyebrow bars.
- Components use tonal surfaces: 8px borderless callouts with semantic shape cues; table header rule only; borderless shadowless code with real language labels; pill tags/badges; hanging quote; filled sequence nodes; raised 8px media and numbered captions. Preserve semantics, keyboard focus, image fallbacks, fit/position, and existing figure variants.
- Media treatments are additive plain/framed/bleed classes or optional props, not a replacement API. Bleed is for cover/section, with an edge gradient and a mode-aware translucent reading zone; explicit image fit remains authoritative. Keep existing custom background support.
- ICT alone uses an 8px blueprint grid at 2.5% opacity on covers/sections and 1.5% on content layouts. Statements/closings remain untextured. Do not restore the old artwork system or fetch decorative images.
- Motion: 520ms / 16px rise; 40ms sequencing on cover/section/statement; native v-click 300ms / 8px rise. Reduced motion, overview, inactive slides and print stay static.
- Preserve genuine bounds/accessibility/interaction checks. Update only assertions explicitly superseded by the selected design (paper colors, typography roles, chrome styling, component treatment). Keep dense fixtures meaningful; fix layout before considering fixture changes.
- Keep edits scoped to this redesign, preserving the existing user changes and `.pi/`. Primary agent owns final fixtures/docs/tests/integration; Luna agents have disjoint runtime/style ownership.

The post-review polish raises the default light cover band to 7% accent and dark marks to 28% highlight. Statement subtitles use 18px and one 16px gap. UCAS cover headings retain balanced wrapping and use OpenType `halt` punctuation spacing; authored text is unchanged.
