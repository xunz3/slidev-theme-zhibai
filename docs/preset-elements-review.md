# Content elements — Veil 0.4

The [selected proposal](./veil-design-proposal.md) defines the current component direction: borderless tonal callouts, a single table header separator, native language labels on muted code surfaces, pill labels, hanging quotations, filled sequence nodes, and raised media with numbered captions. Existing semantic families, accessible media fallbacks, keyboard focus and code scrolling remain part of the contract.

The [expanded content fixture](../fixtures/expanded-content.md) tests dense compositions and the existing component APIs. [Material studies](../fixtures/veil-surfaces.md) covers native language metadata, plain/framed/bleed image treatments and author-owned caption numbers. Preset isolation and accessibility remain required gates.

See the [current implementation review](./veil-review.md) for final verification status and evidence. Earlier component screenshots describe previous styles and are not validation for 0.4.
