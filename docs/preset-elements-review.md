# 三个 preset 的内容元素审查

本轮延续已确定的浅色封面方向，检查正文、目录、表格、代码、引用、图文、参考文献、作者、时间线、章节和结束页。对照源是 `fixtures/elements-gallery.md`：前三十页按 Default、UCAS、ICT 各十页展示相同内容，最后六页验证无编号目录与自定义双栏。

## 三个 preset 的方向

| Preset | 保留的特点 | 本轮优化 |
| --- | --- | --- |
| Default | 象牙白、淡紫、衬线标题与英文引用 | 减轻表头、标签与作者边框；引用署名与正文对齐；让正常和宽松密度有明确的留白递进。 |
| UCAS | 校方原始标识、学术蓝与衬线标题 | 统一标题节奏和双栏宽度；减轻表格线；保持简洁的作者与参考文献排版。 |
| ICT | 冷白、无衬线标题、清晰的技术结构 | 正文强调色与封面的蓝绿色协调；图注和提示标题改用便于中英文阅读的字体；代码、数字与短技术标签继续使用等宽字体。 |

## 审查与处理

1. **目录：清晰，交互可改善。** 保留单列条目，编号改为两位数；悬停与键盘焦点有轻微底色和标题反馈。修复关闭编号后标题仍挤在编号列中的问题。
2. **正文和提示框：基础良好，层级偏紧。** 增加标题与内容之间的间距，降低局部标题字重，略微增加正文页边距。提示框继续用淡底、细边与文字/形状表示语义，不增加大面积深色块。
3. **表格和双栏：可读，但第二栏被重复缩进。** 表头底色、顶底线进一步减轻；双栏使用等宽内容区，分隔线位于间距中央。自定义 `gap` 和 `reverse` 在各 preset 中一致生效，窄窗口按源码顺序堆叠。
4. **代码：改善幅度最大。** 原先短代码也占满一个大型白色面板，代码字号偏小。现在字号更大、内边距更舒展、表面微带 preset 色；短示例随内容收起，长示例仍在代码区域内滚动，保留高亮和复制能力。
5. **引用：保留字体个性，校正对齐。** Default 的署名与引用正文对齐，去掉冗长的署名分隔线。显式标注 `lang="zh"` 的内容保持正体；英文引用保留各 preset 的字体处理。
6. **图文和图注：保留图像完整性，减轻容器。** 图文布局去掉多余的外框与图片留白区底色，保留 `contain` / `cover`、替代文本和加载失败提示。ICT 图注不再使用密集的等宽排版。
7. **参考文献和作者：从卡片改为文稿式信息。** 作者信息用轻量顶部分隔线、姓名、机构和邮箱表达，保持邮箱链接可见。参考条目增加间距，列表规则不再误伤内嵌作者列表。
8. **步骤、时间线和行内元素：结构合理，减轻标签。** 保留原生有序列表、步骤序号、时间线轨道和状态语义。标签去掉虚线框、降低字重，状态徽标保留文字、颜色和可选形状。
9. **章节、强调页与页脚：延续现有方向。** 保留浅色章节面、封面装饰、细页脚线和页码层级。正文的调整通过共同的 preset 色彩变量保持一致；章节与封面构图不需要进一步增加装饰。
10. **结束页：改善信息组合。** 作者样式与正文一致；未提供可选 logo 时，标题和联系方式不再为不存在的 logo 预留一列。

## 动效与阅读

沿用已实现的单次入场，避免正文中的表格、步骤和引用各自连续运动。Default 为轻微上移，UCAS 更缓，ICT 为短距离横向入场。Slidev 的逐步展示仍由作者控制；减少动态效果、打印和预览状态保持静态。

内容区可通过键盘聚焦，焦点有可见轮廓。出现纵向滚动时，在内容区上使用方向键、翻页键和 Home/End 会滚动内容，不会误翻幻灯片。其他幻灯片导航和内部控件维持原有行为。
